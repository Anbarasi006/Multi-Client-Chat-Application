Project Overview


    The application supports public messaging, private messaging, and multiple simultaneous client connections. It also includes client name validation to prevent duplicate usernames and provides a simple way for users to communicate over a network.

Tools and Technologies

   Programming Language:  Python

   Networking:  Socket Programming (TCP)

   Concurrency:  Threading

Project Files

    server.py —  Manages client connections and message distribution.

    client.py —  Connects users to the server and sends or receives messages.

    history_abi.json —  Stores chat history, if JSON-based history storage is implemented
